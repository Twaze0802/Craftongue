# Mainland China → Taiwan vocabulary (original list, v0.1.0)

Compiled by this project from common usage. Check "Context traps" in SKILL.md before replacing.
Format: Mainland term → Taiwan term (note).

- 視頻 → 影片
- 短視頻 / 小視頻 → 短影音
- 軟件 → 軟體
- 硬件 → 硬體
- 網絡 → 網路
- 互聯網 → 網際網路 / 網路
- 程序 → 程式 (computer program only)
- 默認 → 預設
- 屏幕 → 螢幕
- 鼠標 → 滑鼠
- 打印 / 打印機 → 列印 / 印表機
- 服務器 → 伺服器
- 內存 → 記憶體
- 硬盤 → 硬碟
- U盤 → 隨身碟
- 數據庫 → 資料庫
- 算法 → 演算法
- 人工智能 → 人工智慧
- 激活 → 啟用 / 開通
- 登錄 → 登入
- 註銷 (log out) → 登出
- 菜單 → 選單
- 鏈接 → 連結
- 文件夾 → 資料夾
- 二維碼 → QR Code
- 博客 → 部落格
- 短信 → 簡訊
- 視頻通話 → 視訊通話
- 移動端 → 行動版 / 手機版
- 信息 → 資訊 / 訊息 (see traps)
- 支持 (software supports) → 支援
- 兼容 → 相容
- 插件 → 外掛 / 擴充功能
- 卸載 → 解除安裝
- 刷新 → 重新整理
- 設置 → 設定
- 官網 → 官網 (same; convert 官网)
- 賬號 / 账号 → 帳號
- 反饋 → 回饋
- 打印機 (3D) → 3D 列印機 / 3D 印表機
