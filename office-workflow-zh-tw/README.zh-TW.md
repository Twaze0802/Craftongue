# office-workflow-zh-tw

**[English README](README.md)**

給在台灣上班、不會寫程式的人用的 AI 技能（Agent Skill）。只要你用的 AI 工具支援開放的 [Agent Skills](https://agentskills.io) 格式就能用，例如 Claude Code、claude.ai、Codex、Cursor。

## 它會做什麼

**主要功能**
- **回 email：** 用自然的台灣商務語氣回信，原信裡的每個問題都會回到。
- **會議記錄轉待辦：** 整理成「待辦事項／負責人／期限／備註」表格。沒寫到的負責人或期限會標「待確認」，絕不亂猜。
- **產生週報：** 把零散筆記整理成「本週完成／進行中／問題與需要協助／下週計畫」。

**20 種台灣職場範本**
- 請假信、報價、付款提醒、出貨延遲、客訴回覆、離職交接、給家長的通知、停診公告等，格式固定，直接填空。

**專業場景規則**
- 法律、醫療、教育、公文、金融保險、房地產、電商客服、人資、科技產品，共 9 種場景。每種都有台灣用語、常見格式，以及一份「禁止事項」：不自己編法條、藥量、利率或文獻，不替你做法律或醫療判斷，不把個資放進群組訊息，不寫歧視性的徵才條件，不在不合場合的地方用 emoji 或誇大字眼。

**台灣用語分支**
- 把任何文字改寫、潤飾或翻譯成自然的台灣繁體中文（或英文）：去掉 AI 腔、換掉中國用語和網路用語、改成台灣標點，並讓整段語氣一致（正式、商務或聊天）。

**絕不亂編。** 只用你貼上或告訴它的內容。缺的資訊會留下像【請填入：出貨日期】這樣的空格，讓你自己補。

## 安裝

**claude.ai：** 下載 zip 檔，到「設定 → 功能 → 技能」上傳。

**Claude Code：** 把 `office-workflow-zh-tw` 資料夾複製到 `~/.claude/skills/`。

## 個人設定（建議）

填好以後，署名、職稱、稱呼和慣用語氣都會自動套用，不用每次再補【請填入】。兩種方法選一種：

- **最簡單（手機也可以）：** 到 claude.ai「設定 → 個人檔案」的個人偏好欄位，貼上一段以【我的設定】開頭的文字，例如：
  `【我的設定】姓名：王小明／職稱：業務專員／公司：○○股份有限公司／署名：王小明 業務部 分機 123／稱呼對方用「您」／不要出現的詞：親愛的`
- **改檔案：** 打開技能資料夾裡的 `my-profile.md`，照格式填好再上傳。
