# Security / 安全

## What the skills do / 技能會做什麼

The skills in this repo are plain-text instructions (Markdown). They make no network calls, need no API keys, and run no hidden code.
本 repo 的技能都是純文字指示（Markdown），不連外部網路、不需要 API 金鑰，也不會執行隱藏程式。

They never ask for passwords, API keys, bank accounts, credit cards or national ID numbers. If you see a skill do that, treat it as a bug.
技能絕不會要求密碼、API 金鑰、銀行帳號、信用卡或身分證號碼。如果看到技能這樣做，請當成錯誤回報。

## Reporting a problem / 回報問題

Please report security issues privately through GitHub: open the repo's **Security** tab and choose **Report a vulnerability**. Do not post details in a public issue.
請透過 GitHub 私下回報安全問題：到 repo 的 **Security** 分頁，選 **Report a vulnerability**。請不要把細節貼在公開的 issue。

We aim to reply within 7 days.
我們會盡量在 7 天內回覆。
